## 3. 常见问题排错

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| Redis 无 key | 未走 `getQuestionFromCache` | 检查 Controller / judge |
| 改题后仍是旧内容 | 未 evict | update/delete 加 `evictQuestionCache` |
| 判题答案不对 | judge 仍 `getById` 或缓存未 evict | 统一读缓存 + 改题后删 |
| 启动报 Redis 连接失败 | Redis 未开 | 启动 Redis 或 `enabled: false` |
| JSON 反序列化失败 | 字段类型/Date 格式 | 统一 JSONUtil 配置 |
| TTL 为 -1 | set 时未传过期时间 | 检查 `bucket.set(..., ttl, SECONDS)` |
| 已删题仍能看 | 未 evict 逻辑删除 | delete 后 evict |

## 5. 面试问答精选

### Q1：为什么用 Redis 做题目缓存？

**答**：做题页读多写少，同一题目被高频访问；题目含 LaTeX 字段较大，重复查 MySQL 浪费 IO。Redis 内存读写快，降低 DB 压力与 P99 延迟。

### Q2：用的什么缓存模式？

**答**：Cache-Aside。读时先 Redis，miss 查 MySQL 并回填；写时先更新 MySQL，再删除缓存 key。

### Q3：缓存穿透 / 击穿 / 雪崩怎么处理？

**答**：

- 穿透：空值短缓存 + 参数校验  
- 击穿：Redisson 互斥锁 + 双重检查  
- 雪崩：TTL 加随机抖动  

### Q4：为什么删缓存而不是更新缓存？

**答**：题目字段多，更新 Redis 要与 DB 完全一致；删缓存下次读自然加载最新，逻辑简单，且避免事务与缓存更新顺序问题。

### Q5：为什么缓存 Question 不缓存 QuestionVO？

**答**：VO 含 userVO，用户改昵称会导致 VO 过期；Question 与 DB 行一一对应，失效边界清晰。

### Q6：用户做题状态为什么不放进题目缓存？

**答**：状态是用户维度，每用户每题不同，key 会爆炸；独立 `user_question_status` 表查询更清晰。

### Q7：Redis 挂了怎么办？

**答**：读缓存 try-catch 降级直查 DB；配置 `enabled=false`；可加限流保护 DB；生产用 Redis 高可用。

### Q8：和 ES 搜索一致性？

**答**：Redis 管详情实时读，写后删缓存；ES 定时增量同步，搜索最终一致，职责分离。

### Q9：Redisson 和 Jedis 区别？

**答**：Redisson 提供 RBucket、RLock、RBitSet 等高级结构；项目签到已用 BitSet，题目用 RBucket，统一客户端。

### Q10：如何验证缓存生效？

**答**：首次请求后 `redis-cli GET question:detail:2` 有 JSON；再次请求日志 hit；update 后 key 被删。

## 6. 3 分钟项目陈述模板

> 数学刷题平台做题页高频读题目详情。我用 Cache-Aside，Redisson RBucket 存 Question 的 JSON，key 为 `question:detail:{id}`，TTL 30 分钟加随机抖动。穿透用空值缓存，击穿用分布式锁，更新题目先写 MySQL 再删缓存。判题和详情接口统一走缓存读，与用户做题状态分离。本地用 redis-cli 和 ab 压测验证 hit 率。
