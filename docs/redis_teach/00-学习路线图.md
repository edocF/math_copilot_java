> 本系列面向 **不熟悉 Redis** 的开发者，结合 `interview_copilot` 数学刷题项目，从零学会「题目详情缓存」的设计与编码。

## 1. 学完能做什么

- 理解 Redis 是什么、为什么刷题项目需要它
- 在本项目中配置并使用 **Redisson**（项目已引入，签到功能已在用）
- 掌握 **Cache-Aside（旁路缓存）** 读写流程
- 理解并应对 **穿透 / 击穿 / 雪崩**
- 独立写出 `QuestionCacheService` 并接入 `GET /question/get/vo`
- 会用 `redis-cli` 验证缓存是否生效
- 面试中能讲清业务场景与技术选型

## 6. 术语速查（先混个脸熟）


| 术语              | 一句话                             |
| --------------- | ------------------------------- |
| **Redis**       | 内存数据库，读写极快，常作缓存                 |
| **Key**         | 类似 Map 的键，如 `question:detail:2` |
| **Value**       | 键对应的值，我们存 JSON 字符串              |
| **TTL**         | 过期时间，到期 key 自动删除                |
| **命中 / Miss**   | 缓存里有 / 有没                       |
| **Cache-Aside** | 应用自己管缓存，先查缓存再查 DB               |
| **Evict**       | 删除缓存（失效）                        |
| **Redisson**    | Java 的 Redis 客户端，封装了锁、Bucket 等  |
| **RBucket**     | Redisson 的「单个字符串值」容器            |
