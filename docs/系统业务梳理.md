# Interview Copilot 系统业务梳理

> 面试刷题 / 题库管理后端（Spring Boot 2.7 + MyBatis-Plus）。接口前缀：`/api`，默认端口 `8101`。

## 1. 系统定位

面向**面试题目与题库**的内容平台后端：用户可注册登录、浏览题目与题库、搜索题目；管理员维护题库、题目与题库-题目关联；支持文件上传（头像等）与签到等辅助能力。

---

## 2. 核心业务模块

### 2.1 用户（`/user`）

| 能力 | 说明 | 权限 |
|------|------|------|
| 注册 / 登录 | 账号密码；登录返回 JWT（`token` 请求头） | 公开（白名单） |
| 当前登录用户 | `get/login` | 需登录 |
| 个人信息 | `update/my` 改昵称、头像、简介等 | 需登录 |
| 用户 CRUD / 分页 | 管理端用户维护 | **admin** |
| 用户列表 VO | 分页脱敏展示 | 登录即可（单页 ≤20 防爬） |
| 签到 | Redis BitSet 按年记录；`add/sign_in`、`get/sign_in?year=` | 需登录 |

**角色**：`user`（默认）、`admin`、`ban`（封号拦截 `@AuthCheck`）。

### 2.2 题目（`/question`）

| 能力 | 说明 | 权限 |
|------|------|------|
| 详情 / 分页 VO | 含创建者信息 | 读接口多为公开 |
| 增删改 | 标题、内容、标签、推荐答案；`tags` 存 JSON 数组字符串 | 登录用户可增删改（**未严格校验仅本人**） |
| 分页实体 | 原始 `Question` | **admin** |
| ES 搜索 | `search/page/vo`，关键词检索 | 公开；`pageSize` 上限 200 |

题目变更通过定时任务增量同步到 Elasticsearch（`IncSyncQuestionToEs`，每分钟）；全量同步任务 `FullSyncQuestionToEs` 默认未启用。

### 2.3 题库（`/questionBank`）

| 能力 | 说明 | 权限 |
|------|------|------|
| 详情 VO | 题库信息 + 关联题目分页 | 公开 |
| 分页 VO | 列表展示 | 公开 |
| 增删改 / 分页实体 | 标题、描述、封面图 | **admin** |

创建时写入 `userId`（当前登录管理员）。

### 2.4 题库-题目关联（`/questionBankQuestion`）

多对多关系表，维护「某题库包含哪些题」。

| 能力 | 说明 | 权限 |
|------|------|------|
| 单条增删改、分页 | | **admin** |
| 批量加入 / 移出题库 | `batch/add`、`batch/delete` | **admin** |

关联表为**物理删除**（无 `isDelete`），且 `(questionBankId, questionId)` 唯一。

### 2.5 文件（`/file`）

- 上传至腾讯云 COS，按业务目录划分。
- 当前业务枚举：`user_avatar`（用户头像），单文件 ≤2MB，类型 jpg/bmp/gif/png。

## 3. 数据模型

### 3.1 ER 关系（概念）

```
user ──┬──< question          (题目创建者)
       ├──< question_bank     (题库创建者)
       └──< question_bank_question (关联操作者)

question_bank ──< question_bank_question >── question
                    (多对多，中间表)
```

### 3.2 表结构要点

| 表 | 核心字段 | 删除策略 |
|----|----------|----------|
| **user** | account、password、name、avatar、profile、**userRole** | 逻辑删除 `isDelete` |
| **question** | title、content、**tags(JSON)**、answer、userId | 逻辑删除 |
| **question_bank** | title、description、picture、userId | 逻辑删除 |
| **question_bank_question** | questionBankId、questionId、userId | **硬删除**；唯一约束防重复 |

公共字段：`createTime`、`updateTime`；user/question/question_bank 另有 `editTime`。

### 3.3 与搜索侧数据

- MySQL 为权威数据源。
- ES 索引 `question`，文档 `QuestionEsDto`（id、title、content、tags、answer、userId、时间等）。
- 增量同步依赖 `updateTime` 及含已删数据的查询（`getQuestionWithDeleted`）。

### 3.4 非关系型数据

- **Redis**：用户签到 BitSet，key 按 `年 + userId` 组织（Redisson）。
- **COS**：用户上传文件 URL。

## 4. 技术架构（简）

```
Client ──token──> UserInfoInterceptor ──> UserContext
                      │
                      ├── 白名单：/user/login、/user/register
                      └── @AuthCheck AOP（admin / ban）

Controller → Service → Mapper(MySQL)
                    └→ QuestionEsDao(ES)
                    └→ CosManager / Redisson
```

**依赖栈**：MySQL + Druid、Redis/Redisson、Elasticsearch、腾讯云 COS、Knife4j 文档、JWT（JKS）、Spring Session（配置预留分布式 session）。

---

## 5. 权限与鉴权小结

1. 除登录/注册外，全局拦截器解析 JWT，写入 `UserContext`。
2. 敏感写操作通过 `@AuthCheck(mustRole = "admin")` 限制。
3. **题目**的增删改目前仅需登录，**未**按 `userId` 限制为本人或管理员。
4. 题库、关联、用户管理均为管理员专属。

---

## 6. 种子数据

`init_data.sql` 预置约 20 个题库、20 道题及若干 `question_bank_question` 关联，便于本地联调（前端/面试场景 demo）。

---

## 7. 尚未实现 / 待完善（从代码可见）

- 面试模拟、AI 答题、收藏、评论等 C 端互动能力未见。
- 题目写操作与 ES 之间无实时双写，依赖定时增量同步。
- COS、ES、Redis 等需在 `application.yml` 中按环境配置。
- 分布式 Session、全量 ES 同步任务多为注释/未启用状态。

## 8. API 一览（按模块）

| 模块 | 主要路径 |
|------|----------|
| 用户 | `/user/register`、`/login`、`/get/login`、`/update/my`、`/add|get/sign_in`、管理端 CRUD |
| 题目 | `/question/get/vo`、`/list/page/vo`、`/add|update|delete`、`/search/page/vo` |
| 题库 | `/questionBank/get/vo`、`/list/page/vo`、管理端 CRUD |
| 关联 | `/questionBankQuestion/*`、`/batch/add`、`/batch/delete` |
| 文件 | `/file/upload` |

完整参数与示例见 Knife4j：`/api/doc.html`（开发环境）。
